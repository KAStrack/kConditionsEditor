Skins

The same rule, the same markup, five stylesheets. Every skin is fully editable — click a field name, an operator or a value in any of them.

Both independent of the skin — point at +AND, OR(…) or a × in any of them.

boxed

skin: 'boxed'

The original. Explicit, but the borders compete with the logic.

equation

skin: 'equation'

Brackets and indentation carry the grouping; AND/OR sit between the lines.

blackboard

skin: 'blackboard'

The same layout on a dark board, chalk palette, values in chalk yellow.

ledger

skin: 'ledger'

Least ink. Hairline guides instead of brackets; a negated group's guide goes dashed.

prose

skin: 'prose'

The rule pretty-printed: real parentheses, indentation by depth, closing bracket on its own line.
